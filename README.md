# Jamal Abuattaya Portfolio

A bilingual personal portfolio for Jamal Hassan Yousef Abuattaya, focused on software development and application security.

## Included sections

- Personal introduction and academic progress
- Technical skills across development, security, data, and networking
- Current university and diploma education
- Seven verified course certificates with PDF links
- One selected React.js project: Alasema Restaurant
- Contact links and downloadable CV

## Run locally

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```

The site is built with React, Vinext/Next.js conventions, TypeScript, and responsive CSS.
