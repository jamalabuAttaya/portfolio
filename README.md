# Jamal Hassan Abu Attaya — Portfolio

A bilingual, responsive portfolio focused on software development, mobile computing, and application security.

## Included sections

- Personal introduction and academic progress
- Technical skills across development, security, data, and networking
- Current university and diploma education
- Eight verified course certificates with language-specific previews and PDF links
- Three live projects: Alasema Restaurant, Shahd Falyouna Portfolio, and Dev Nexus Academy
- English and Arabic routes with matching project and certificate media
- Dark and light themes with saved user preference
- Search metadata, structured data, sitemap, robots policy, and a custom site icon
- Hardened HTTP security headers
- Contact links and downloadable CV

## Run locally

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Quality checks

```bash
npm test
npm audit
```

The production project uses Next.js, React, TypeScript, and responsive CSS. It is ready for deployment on Vercel.
